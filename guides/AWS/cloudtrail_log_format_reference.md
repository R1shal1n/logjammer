**Official SecOps Log Type:** `AWS_CLOUDTRAIL`

# AWS CloudTrail Log Format Reference

## Complete JSON Structure

CloudTrail log files contain a `Records` array with one or more event records. Each record has the following structure:

```json
{
  "Records": [{
    "eventVersion": "String",
    "eventTime": "String",
    "eventSource": "String",
    "eventName": "String",
    "eventType": "String",
    "eventID": "String",
    "eventCategory": "String",
    "awsRegion": "String",
    "sourceIPAddress": "String",
    "userAgent": "String",
    "userIdentity": {
      "type": "String",
      "principalId": "String",
      "arn": "String",
      "accountId": "String",
      "accessKeyId": "String",
      "userName": "String",
      "sessionContext": {
        "sessionIssuer": {
          "type": "String",
          "principalId": "String",
          "arn": "String",
          "accountId": "String",
          "userName": "String"
        },
        "webIdFederationData": {},
        "attributes": {
          "creationDate": "String",
          "mfaAuthenticated": "String"
        }
      },
      "invokedBy": "String"
    },
    "requestParameters": {},
    "responseElements": {},
    "additionalEventData": {},
    "requestID": "String",
    "readOnly": "Boolean",
    "resources": [{
      "ARN": "String",
      "accountId": "String",
      "type": "String"
    }],
    "recipientAccountId": "String",
    "serviceEventDetails": {},
    "sharedEventID": "String",
    "vpcEndpointId": "String",
    "vpcEndpointAccountId": "String",
    "errorCode": "String",
    "errorMessage": "String",
    "managementEvent": "Boolean",
    "apiVersion": "String",
    "addendum": {
      "reason": "String",
      "updatedFields": "String",
      "originalRequestID": "String",
      "originalEventID": "String"
    },
    "sessionCredentialFromConsole": "String",
    "edgeDeviceDetails": {},
    "tlsDetails": {
      "tlsVersion": "String",
      "cipherSuite": "String",
      "clientProvidedHostHeader": "String"
    },
    "eventContext": {
      "requestContext": {
        "aws:ViaAWSService": "String"
      },
      "tagContext": {}
    }
  }]
}
```

## Field Definitions and Data Types

### Top-Level Event Fields

#### eventVersion (String, Required)
- **Type**: String
- **Optional**: False
- **Description**: The version of the log event format. Current version is 1.11
- **Format**: major_version.minor_version (e.g., "1.11")
- **Since**: 1.0

#### eventTime (String, Required)
- **Type**: String (ISO 8601 format)
- **Optional**: False
- **Description**: The date and time the request was completed, in UTC
- **Format**: "YYYY-MM-DDTHH:MM:SSZ" (e.g., "2023-07-19T21:17:28Z")
- **Since**: 1.0

#### eventSource (String, Required)
- **Type**: String
- **Optional**: False
- **Description**: The AWS service that the request was made to
- **Format**: Short form service name + ".amazonaws.com"
- **Examples**:
  - "ec2.amazonaws.com"
  - "s3.amazonaws.com"
  - "iam.amazonaws.com"
  - "cloudtrail.amazonaws.com"
- **Since**: 1.0

#### eventName (String, Required)
- **Type**: String
- **Optional**: False
- **Description**: The requested action (API operation name)
- **Examples**:
  - "StartInstances"
  - "CreateUser"
  - "CreateBucket"
  - "PutObject"
  - "GetObject"
  - "ListBuckets"
  - "DescribeInstances"
- **Since**: 1.0

#### eventType (String, Required)
- **Type**: String
- **Optional**: False
- **Description**: Identifies the type of event
- **Possible Values**:
  - "AwsApiCall" - An API was called
  - "AwsServiceEvent" - The service generated an event
  - "AwsConsoleAction" - Console action that was not an API call
  - "AwsConsoleSignIn" - User signed in to AWS Console
  - "AwsCloudTrailInsight" - CloudTrail Insights event
  - "AwsVpceEvents" - Network activity event
- **Since**: 1.02

#### eventID (String, Required)
- **Type**: String (GUID)
- **Optional**: False
- **Description**: GUID generated by CloudTrail to uniquely identify each event
- **Example**: "9cb5f426-7806-46e5-9729-exampled135d"
- **Since**: 1.01

#### eventCategory (String, Required)
- **Type**: String
- **Optional**: False
- **Description**: Shows the event category
- **Possible Values**:
  - "Management" - Management events
  - "Data" - Data events
  - "NetworkActivity" - Network activity events
  - "Insight" - Insights events
- **Since**: 1.07

#### awsRegion (String, Required)
- **Type**: String
- **Optional**: False
- **Description**: The AWS Region that the request was made to
- **Examples**: "us-east-1", "us-west-2", "eu-west-1"
- **Since**: 1.0

#### sourceIPAddress (String, Required)
- **Type**: String
- **Optional**: False
- **Description**: The IP address that the request was made from
- **Examples**:
  - "192.0.2.0"
  - "AWS Internal/#" (for AWS-originated events)
- **Since**: 1.0

#### userAgent (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: The agent through which the request was made
- **Max Size**: 1 KB (truncated if exceeded)
- **Examples**:
  - "aws-cli/2.13.5 Python/3.11.4 Linux/4.14.255-314-253.539.amzn2.x86_64"
  - "aws-sdk-java"
  - "aws-sdk-ruby"
  - "lambda.amazonaws.com"
  - "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:133.0) Gecko/20100101 Firefox/133.0"
- **Since**: 1.0

#### requestID (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: The value that identifies the request (service-generated)
- **Max Size**: 1 KB
- **Example**: "e4336db0-149f-4a6b-844d-EXAMPLEb9d16"
- **Since**: 1.01

#### recipientAccountId (String, Optional)
- **Type**: String (12-digit account ID)
- **Optional**: True
- **Description**: The account ID that received this event
- **Example**: "123456789012"
- **Since**: 1.02

#### readOnly (Boolean, Optional)
- **Type**: Boolean
- **Optional**: True
- **Description**: Identifies whether this operation is read-only
- **Values**:
  - true - Read-only operation (e.g., DescribeTrails)
  - false - Write operation (e.g., DeleteTrail)
- **Since**: 1.01

#### managementEvent (Boolean, Optional)
- **Type**: Boolean
- **Optional**: True
- **Description**: Identifies whether the event is a management event
- **Values**: true, false
- **Since**: 1.06

#### apiVersion (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: Identifies the API version associated with AwsApiCall events
- **Since**: 1.01

### userIdentity Object (Required)

#### type (String, Required)
- **Type**: String
- **Optional**: False
- **Possible Values**:
  - "Root" - Request made with AWS account credentials
  - "IAMUser" - Request made with IAM user credentials
  - "AssumedRole" - Request made with temporary credentials from AssumeRole
  - "Role" - Request made with persistent IAM identity
  - "FederatedUser" - Request made with temporary credentials from GetFederationToken
  - "Directory" - Request made to directory service
  - "AWSAccount" - Request made by another AWS account
  - "AWSService" - Request made by AWS service
  - "IdentityCenterUser" - Request made on behalf of IAM Identity Center user
  - "Unknown" - Unknown identity type

#### principalId (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: Unique identifier for the entity that made the call
- **Example**: "AIDAJ45Q7YFFAREXAMPLE"

#### arn (String, Optional)
- **Type**: String (ARN format)
- **Optional**: True
- **Description**: The ARN of the principal that made the call
- **Example**: "arn:aws:iam::123456789012:user/Alice"

#### accountId (String, Optional)
- **Type**: String (12-digit account ID)
- **Optional**: True
- **Description**: The account that owns the entity
- **Example**: "123456789012"

#### accessKeyId (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: The access key ID used to sign the request
- **Example**: "AKIAIOSFODNN7EXAMPLE"
- **Note**: May be empty for security reasons

#### userName (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: The friendly name of the identity
- **Behavior by type**:
  - Root (no alias): Not present
  - Root (alias set): The account alias
  - IAMUser: The IAM user name
  - AssumedRole: Not present (found in sessionContext)
  - Role: User-defined
  - Others: Varies

#### sessionContext (Object, Optional)
Contains information about the session for temporary credentials.

**sessionIssuer** (Object):
- `type` (String): Source of temporary credentials (Root, IAMUser, Role)
- `principalId` (String): Internal ID of entity
- `arn` (String): ARN of source entity
- `accountId` (String): Account that owns the entity
- `userName` (String): Friendly name of role/user

**attributes** (Object):
- `creationDate` (String): When credentials were issued (ISO 8601)
- `mfaAuthenticated` (String): "true" or "false"

**webIdFederationData** (Object, Optional):
- `federatedProvider` (String): Identity provider principal name
- `attributes` (Object): Application ID and user ID from provider

#### invokedBy (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: Name of AWS service that made the request
- **Example**: "ec2.amazonaws.com"

### Request and Response Fields

#### requestParameters (Object, Required)
- **Type**: Object/JSON
- **Optional**: False
- **Max Size**: 100 KB (omitted if exceeded)
- **Description**: Parameters sent with the request
- **Content**: Service-specific, documented in AWS API references

#### responseElements (Object, Required)
- **Type**: Object/JSON
- **Optional**: False (null for readOnly APIs)
- **Max Size**: 100 KB (omitted if exceeded)
- **Description**: Response elements for create/update/delete actions
- **Content**: Service-specific API responses

#### additionalEventData (Object, Optional)
- **Type**: Object/JSON
- **Optional**: True
- **Max Size**: 28 KB
- **Description**: Additional data about the event not in request/response

#### serviceEventDetails (Object, Optional)
- **Type**: Object/JSON
- **Optional**: True
- **Max Size**: 100 KB
- **Description**: Service event details including what triggered event

### Resource Information

#### resources (Array, Optional)
- **Type**: Array of Objects
- **Optional**: True
- **Description**: List of resources accessed in the event

**Resource Object Structure**:
```json
{
  "ARN": "String",
  "accountId": "String",
  "type": "String"
}
```

**Fields**:
- `ARN` (String): Resource ARN
- `accountId` (String): Account ID of resource owner
- `type` (String): Resource type in format "AWS::service-name::data-type-name"
  - Example: "AWS::IAM::Role"

### Error Information

#### errorCode (String, Optional)
- **Type**: String
- **Optional**: True
- **Max Size**: 1 KB
- **Description**: AWS service error if request returns an error
- **Examples**:
  - "TrailNotFoundException"
  - "VpceAccessDenied"
  - "QueryIdNotFoundException"

#### errorMessage (String, Optional)
- **Type**: String
- **Optional**: True
- **Max Size**: 1 KB
- **Description**: Error description message
- **Example**: "Unknown trail: arn:aws:cloudtrail:us-east-1:111122223333:trail/myTrail2"

### Network and Security

#### tlsDetails (Object, Optional)
- **Type**: Object
- **Optional**: True
- **Description**: TLS connection information

**Fields**:
- `tlsVersion` (String): TLS version (e.g., "TLSv1.2", "TLSv1.3")
- `cipherSuite` (String): Cipher suite used (e.g., "ECDHE-RSA-AES128-GCM-SHA256")
- `clientProvidedHostHeader` (String): FQDN used in API call

**Note**: Not present if:
- API call made by AWS service on your behalf
- sessionCredentialFromConsole is true and proxy client used

#### vpcEndpointId (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: VPC endpoint ID for requests from VPC

#### vpcEndpointAccountId (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: AWS account ID of VPC endpoint owner
- **Since**: 1.09

#### sessionCredentialFromConsole (String, Optional)
- **Type**: String
- **Optional**: True
- **Description**: Shows if event originated from AWS Console session
- **Values**: "true" or "false"
- **Note**: Only shown when value is "true"
- **Since**: 1.08

### Special Event Fields

#### sharedEventID (String, Optional)
- **Type**: String (GUID)
- **Optional**: True
- **Description**: GUID for CloudTrail events from same AWS action sent to different accounts
- **Note**: Only present when events delivered to multiple accounts
- **Since**: 1.03

#### addendum (Object, Optional)
- **Type**: Object
- **Optional**: True
- **Description**: Information about event delivery delays or corrections
- **Since**: 1.08

**Fields**:
- `reason` (String): Why event was delayed/corrected
  - "DELIVERY_DELAY" - Delay in delivering events
  - "UPDATED_DATA" - Field was missing or incorrect
  - "SERVICE_OUTAGE" - Service outage (rare)
- `updatedFields` (String): Fields updated (if reason is UPDATED_DATA)
- `originalRequestID` (String): Original request ID
- `originalEventID` (String): Original event ID

#### eventContext (Object, Optional)
- **Type**: Object
- **Optional**: True
- **Description**: Enriched event data with resource tags and IAM condition keys
- **Note**: Only in event data stores configured for enrichment
- **Since**: 1.11

**Fields**:
- `requestContext` (Object): IAM global condition keys evaluated
- `tagContext` (Object): Tags on resources and IAM principals

## Field Size Limits and Truncation

### Standard Event Size (256 KB max)
- **userAgent**: 1 KB max (truncated)
- **requestID**: 1 KB max (truncated)
- **errorCode**: 1 KB max (truncated)
- **errorMessage**: 1 KB max (truncated)
- **additionalEventData**: 28 KB max (omitted if exceeded)
- **requestParameters**: 100 KB max (omitted if exceeded)
- **responseElements**: 100 KB max (omitted if exceeded)
- **serviceEventDetails**: 100 KB max (omitted if exceeded)

### Large Event Size (1 MB max, for event data stores)
When event payload exceeds 1 MB, fields are truncated in this order:
1. annotation
2. requestID
3. additionalEventData
4. serviceEventDetails
5. userAgent
6. errorCode
7. eventContext
8. responseElements
9. requestParameters
10. errorMessage

## Implementation Notes for Log Generator

1. **Required Fields**: Always include eventVersion, eventTime, eventSource, eventName, eventType, eventID, eventCategory, awsRegion, sourceIPAddress, userIdentity, requestParameters, responseElements, recipientAccountId

2. **Conditional Fields**:
   - Include `errorCode` and `errorMessage` only for error scenarios
   - Include `sessionContext` for AssumedRole and FederatedUser types
   - Include `tlsDetails` for most API calls (except when invoked by AWS services)
   - Include `resources` array for operations that involve specific resources

3. **Data Types**:
   - Strings: Most fields
   - Booleans: readOnly, managementEvent
   - Objects: userIdentity, requestParameters, responseElements, tlsDetails
   - Arrays: Records (top-level), resources

4. **Time Formats**:
   - eventTime: ISO 8601 format "YYYY-MM-DDTHH:MM:SSZ"
   - creationDate: ISO 8601 format "YYYY-MM-DDTHH:MM:SSZ"

5. **ID Formats**:
   - eventID: GUID format
   - requestID: Service-specific format
   - accountId: 12-digit number
   - accessKeyId: Starts with "AKIA" or "ASIA" (for temporary credentials)
   - principalId: Service-specific format

6. **Common Patterns**:
   - Management events: eventCategory = "Management", managementEvent = true
   - Data events: eventCategory = "Data"
   - Read operations: readOnly = true
   - Write operations: readOnly = false, responseElements contains created/modified resources
   - Error responses: Include errorCode and errorMessage, responseElements = null

7. **Service-Specific eventSource Patterns**:
   - Format: {service}.amazonaws.com
   - Examples: ec2.amazonaws.com, s3.amazonaws.com, iam.amazonaws.com

8. **UserAgent Patterns**:
   - AWS CLI: "aws-cli/{version} Python/{version} {OS}"
   - SDK: "aws-sdk-{language}"
   - Console: Browser user agent string
   - AWS Service: "{service}.amazonaws.com"
